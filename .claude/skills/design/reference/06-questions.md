# フェーズ6: 不明点・詰める必要のある点の洗い出し

作業フォルダ(`<作業フォルダ>`)の場所と共通の決まりは [SKILL.md](../SKILL.md)にある。

## 前提
未決は、どのフェーズでも、見つけた時点で QA.md に足してよい。

## 成果物
`<作業フォルダ>/QA.md`。**今の未決だけ**を置く。

## 項目の書式(すべての項目が必須)
```
## Q01 <質問の見出し>
- 質問:
- 背景:(事実と根拠 repo名:path:line。確かめていないなら、そう書く)
- 選択肢:
  - A: <内容> — 影響: <画面/API/データ/既存への影響>
  - B: <内容> — 影響:
- 推奨案: <A か B と、その理由>
- 反映先: <search/・spec/ のファイル名、spec.md の節>
```
- ID は Q01 からの連番

## 運用
- 未決の推奨案は「仮」として、最終仕様(spec.md)と変更仕様(spec/)の該当する行に載せる([SKILL.md](../SKILL.md) の共通の決まり)
- 回答を得たら、まず反映先(search/・spec/ のファイルと、最終仕様 spec.md)へ反映し(「仮」を外す)、**反映してから** QA.md の項目を消す。決まった中身は spec.md に直接書く
- 解決した項目を QA.md に残さない。未決が無くなったら、QA.md を消してよい

## 完了条件
- [ ] すべての項目に 質問・背景・選択肢と影響・推奨案・反映先 がある
- [ ] spec/・search/ の側から QA の ID を参照していない
- [ ] QA.md に解決した項目が残っていない
- [ ] spec.md と spec/ の中の「仮」と、QA.md の未決が対応している
