# 見本のエビデンス

エビデンスビューアを、Driveもログインも無しで見てもらうための見本。

同じサイトのビューアを `evidence/?base=sample/` で開く。

- **実際の開発のエビデンスではない。** 「アイデア帳」という架空のアプリの画面を、その場で描いて作ったもの
- 動画・画像・テキスト・`manifest.json` が一通り入っていて、`manifest.json` の書き方の見本にもなる
- 形の決まりは [../../docs/evidence-manifest.md](../../docs/evidence-manifest.md)

| ファイル | 何を見せているか |
|---|---|
| `01-list-shows-items.png` | 一覧(画像の項目) |
| `02-detail-opens.png` | 行を選んだ詳細(画像の項目) |
| `03-empty-state.png` | 1件も無い時(`partial` の項目) |
| `04-add-row.webm` | 入力して行が足される流れ(動画の項目) |
| `00-test.txt` | 添付(テキストとして開く) |

本物のエビデンスはここに置かない。Driveのフォルダに置いて `?folder=<ID>` で開く。
