# フェーズ3: 関連する機能の整理

作業フォルダ(`<作業フォルダ>`)の場所と共通の決まりは `design` スキルにある。

## 手順
1. 調べるリポジトリを決める。スキルを呼び出したリポジトリ(cwd)と、イシューやPRに出てくる関連リポジトリ(画面とAPIが別のリポジトリなど)。手元の場所が分からなければ、ユーザーに聞く
2. 要件のキーワード(データの名前・API・画面の名前・用語)で、各リポジトリを検索する(読むだけ)
3. 影響しうるものを、次の区分で洗い出す(プロジェクトに無い区分は除く)
   - 画面
   - API
   - データ(テーブル・モデル・マスタ・設定)
   - 処理(計算・判定・バッチ・定期実行・通知・外部サービスとの連携)
4. 各項目に「なぜ関連するか」を1行で付ける
5. **似た機能を洗い出す**(動きの調べはフェーズ4)
   - 同じ種類の機能・画面・API を、関係するリポジトリから探し、2〜3件を挙げる
   - 各件に「なぜ似ているか」を1行で付ける
   - 見つからない時は「類似なし(探した範囲)」と書く
