# UI

読む時機: 画面を足す、または表示を変える時。

## 今ある画面に揃える
- 新しい表示を作る前に、同じ種類の既存の画面・部品(コンポーネント)を、画面のコードから探し、揃える先を `repo名:path:line` で示す
- 揃えられない時は理由を書き、QA.md に起こす

## まったく新しい表示の時
次を仕様で詰めてから確定する。
- どの画面のどこに出すか
- 何を表示するか(項目・並び・書式)
- 表示する条件(権限・データの状態)

## 画面の状態
- 正常系以外(空・エラー・読み込み中・権限なし)の表示を必ず書き出す
- 画面の変更が大きい時は、画面イメージ(SVG など)を `<作業フォルダ>/images/` に作り、`spec.md` に相対パスで埋め込む(`![一覧の画面](images/list.svg)`)
