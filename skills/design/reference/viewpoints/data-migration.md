# データ移行

読む時機: テーブルや列、データの持ち方を変える時。マスタ・設定・初期データを足す・変える・消す時。

## 仕様に必ず書くこと
- 変えるもの(テーブル・列・マスタ・設定)と、その参照元(処理・画面・API・バッチ・管理画面)を、関係するリポジトリから洗い出す
- 今あるデータ(行)が、変更の後にどうなるか(そのまま・埋める値・消す・使えなくする)
- マスタや設定を消す・無効にした後、それを参照している既存のデータがどう動くか(画面に何が出るか、選べるか、計算や処理に使われるか)
- リリース直後の状態(初期データとして入る値と、その対象)
- 移行が途中で失敗した時、やり直した時(2回流しても壊れないか)
- 戻し方(戻せない時は、戻せないことを書く)

## してはいけないこと
- マスタや設定の登録・更新・削除、マイグレーションを実行して確かめる(読み取りの操作とコードを読むことまで)
