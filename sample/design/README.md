# 設計ビューアの見本

ビューアの見本。実際の開発の設計ではなく、架空の「アイデア帳」にアイデアを消す機能を足す話を書いた作り物。
設計ビューアを `?folder=sample` を付けて開くと見られる(Driveもログインも要らない)。

エビデンスビューアの見本([`sample/evidence/`](../evidence/))と同じ話になっている。
設計ビューアの一覧の「テスト・エビデンス」から、その見本へ移れる(消す機能のテストケースは、まだ行っていない項目として入っている)。

| ファイル | 何を見せているか |
|---|---|
| `index.md` `QA.md` `spec.md` `acceptance.md` `test.md` | 作業フォルダの直下の決まったファイル(一覧に呼び名で出る) |
| `search/` `spec/` | 下書きのフォルダ(一覧に「調査」「変更仕様」として出る) |
| `images/` | 文書に埋め込む画面イメージ |

URLから読む時はフォルダの中身を一覧できないので、ビューアは `index.md` などの決まったファイルから、相対リンクをたどって文書を集める。
