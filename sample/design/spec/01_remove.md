# 消すの変更仕様

| 条件 | 今 | 変更後 |
|---|---|---|
| 一覧を開く | 行に「消す」が無い | 各行の右に「消す」が出る |
| 「消す」を押す | (ボタンが無い) | 確かめの窓が出る |
| 確かめの窓で「消す」 | (窓が無い) | 行が無くなり、`消しました` が出る |
| 確かめの窓で「やめる」 | (窓が無い) | 何も変わらない |
| 最後の1件を消す | (消せない) | 案内 `まだアイデアがありません` が出る(1件も無い時の今の表示と同じ) |

1. 一覧の各行の右に「消す」を置く
2. 押したら確かめの窓を出し、「消す」で消す
   - 窓を閉じたら、フォーカスを一覧に戻す

```text
「ひとつめ」を消しますか?
[やめる] [消す]
```
